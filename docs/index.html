A Research Prototype

DeScideratum

Recomposable research — a living document made of nanopublications, mostly live and interactive except where it is not.
A scientific citation is normally just a name and a year — a pointer you have to trust, or spend hours tracking down and re-deriving yourself to check. This prototype rebuilds a paper as something closer to a living document: individually addressable, independently citable pieces — nanopublications, in the terminology this project builds on — some of which run as real, working code instead of sitting inert. Where a citation says a method was applied, you can run that same method yourself, on your own data, right here, and check it rather than trust it. Not every citation can or should work this way — the honest cases where one can't are shown too, not hidden. Below are working demonstrations, real historically real papers and real authoring tools, rebuilt this way, running entirely in your browser with nothing installed and nothing sent to any server.

How Much Should You Trust an Average?

Three statistics papers, 1979–1997, on estimating uncertainty from a small sample. Each later method genuinely calls the earlier one — a real two-hop citation chain, running live on data you type in yourself.
Lineage 2 of 3 — Live

How Many of These Discoveries Are Real?

Two statistics papers, 1995–2002, on the problem of running many tests at once. Also shows a real, honest case where a citation can't become live code — and explains exactly why, rather than hiding it.
Lineage 3 of 3 — Live

What Happens When You Combine Evidence?

Three statistics papers, 1954–2002, on pooling several studies into one honest estimate. The first demonstration where every input carries its own applicability conditions — population, measurement context, known failure modes — in the open.

A Vignette Concerning Its Own Citability

The three lineages above are hand-built HTML — proof the mechanism works. This one is different: an independent, open-source authoring tool (MyST Markdown) running the resampling lineage's citation through a real plugin, cite-invoke, built for this project by reading MyST's own source code and confirmed working end to end. It's the first known implementation anywhere — including at NeuroLibre, the closest comparable project — that makes citing a method and running it the same act inside an existing scientific publishing tool, not just inside a page we built ourselves.
cite-invoke plugin, MIT licensed, released — install / release notes

A Vignette on Honest Citation

The first vignette proved a citation can run as live code inside an independent authoring tool. This one tests something that couldn't: whether a citation that correctly can't become live code — Benjamini & Yekutieli's proof about correlated tests, a mathematical property rather than a runnable procedure — sits naturally beside two that do, in real narrative prose, without reading as an omission. cite-invoke, installed here from its published release rather than rebuilt.

A Vignette on Conditions That Travel With a Number

Tests a third, different property: whether a citation's Applicability Profile — the population, conditions, and known weaknesses a number is actually valid under — survives being stated in real prose, rather than only existing as a field in a table a reader could scroll past. Two specific studies are named directly in the text, not just listed in a widget.
More demonstrations are planned. Each is an independent, working artifact — open one, view its source, or read its full glossary and methodology directly on the page.

The Citation Horizon

The three lineages above prove citations can run. This traces the opposite end: real citation ancestry checked upstream of the resampling lineage's own root paper, Efron (1979) — discovering the widely-assumed Efron→Quenouille/Tukey citation doesn't exist in Efron's actual reference list, a real DOI that resolves to a one-page abstract commonly cited with a fabricated page range, and a genuine, verified citation horizon where the trail doesn't thin out, it stops.
